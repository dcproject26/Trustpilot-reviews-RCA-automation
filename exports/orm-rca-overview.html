Headout ORM RCA

AI-assisted root-cause analysis for Trustpilot reviews — system overview · July 2026

What it does

Reviews land from Trustpilot (via Slack channels), get matched to a booking, classified against the CX taxonomy, and turned into a structured RCA draft plus a suggested customer response — all reviewed and sent by a CE associate from a single dashboard. Runs in MOCK_MODE today; each connector flips to live independently.

The pipeline (per review)

  1. Ingest & translate — non-English reviews translated before analysis.
  2. Booking match, tiered — Tier 1: BID regex \b\d{7,12}\b (7–12 digits, catches 11-digit BIDs) · Tier 2: signal extraction + BigQuery name match — single hit auto-matches, multiple hits open a candidate picker for the associate · Untraceable if nothing matches. Every step is logged to a confidence trail shown in the UI.
  3. Context pull — booking timeline, experience insights, similar support tickets & reviews (same vendor, recent window), DSS policy recommendation.
  4. Classification (single Claude call) — L1 category, L2 issue type, and sub-theme in one shot, then a validator + salvage layer checks every field against the taxonomy: invalid L1 recovered from a valid L2, sub-themes salvaged by code prefix or fuzzy name, malformed JSON (fences, comments, trailing commas, arrays-instead-of-objects) repaired or safely degraded — the pipeline never breaks on a bad model response.
  5. Structured RCA draft — stated issue, diagnostic checks, what-went-wrong, support/SP interaction frames, areas of improvement, actions taken (SP / customer / business / product / CE), resolution. Every field editable in the dashboard.
  6. Response draft + actions — suggested public reply, optional flag-to-business message, RCA posted back to the Slack thread on send.
