C. Attachment-first BID extraction. Trustpilot's Slack integration posts as attachments with a "reference"-titled field. Change the extractor to try attachments first, regex second:

booking_id = None
# Step 1: attachments
for att in event.get('attachments', []):
    for field in att.get('fields', []):
        title = (field.get('title') or '').lower()
        if 'reference' in title and field.get('value'):
            booking_id = field['value'].strip()
            break
    if booking_id:
        break
# Step 2: regex fallback on text + attachment text/fallback
if not booking_id:
    text = event.get('text', '') or ''
    for att in event.get('attachments', []):
        text += ' ' + (att.get('text') or '') + ' ' + (att.get('fallback') or '')
    m = re.search(BID_REGEX, text)   # keep existing \b\d{7,12}\b — safer than 2024's \b\d{6,}\b
    if m:
        booking_id = m.group(0)
Do NOT loosen BID_REGEX — the 2024 \b\d{6,}\b over-matches on dates, prices, unrelated IDs.
