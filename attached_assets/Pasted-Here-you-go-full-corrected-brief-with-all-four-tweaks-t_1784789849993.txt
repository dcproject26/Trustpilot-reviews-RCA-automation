### Part 1 — Concurrency guards (module-level `asyncio.Semaphore`)

Three semaphores, one per external service. Each protects **every** caller, not just this delta.

**`server/services/bq_connector.py`:**
```python
import asyncio
_BQ_SEM = asyncio.Semaphore(5)   # BigQuery: cap 5 concurrent queries

async def run_query(sql, params=None):
    t0 = _now()
    async with _BQ_SEM:
        waited = _now() - t0
        if waited > 2.0:
            log.warning(f"[bq_connector] wait time exceeded 2s: {waited:.1f}s")
        # ... existing query body ...
```
If `run_query` is currently sync, wrap the outer callers instead (or make it async).

**`server/services/zendesk.py`:** module-level `_ZD_SEM = asyncio.Semaphore(10)` around every HTTP call to Zendesk (search + comments + tags). Same "wait > 2s" warning line.

**`server/services/claude.py`:** module-level `_CL_SEM = asyncio.Semaphore(8)` around `_call()`. Same warning.

**Rules for all three:**
- Module-level, initialized once. Not per-request.
- MOCK_MODE must skip the semaphore (no external call = no need to wait).
- Do not add the semaphore inside `insights.py` — the one in `bq_connector.py` already covers it.

**New file `server/services/insights.py`** — 5 queries, run **in parallel via `asyncio.gather()`**. All parameter-bound. `SAFE_DIVIDE`, `COALESCE(x, 0)`.

**A. Similar reviews (same TID + VID, matching L2, last 30d):**
```sql
SELECT COUNT(DISTINCT r.booking_id) AS c
FROM `headout-analytics.analytics_reporting.fct_reviews` r
LEFT JOIN `headout-analytics.analytics_reporting.fct_bookings` b
  ON r.booking_id = b.booking_id
LEFT JOIN UNNEST(r.issues) AS iss
LEFT JOIN UNNEST(iss.l2_issues) AS l2v
WHERE b.tour_id = @tid AND b.vendor_id = @vid
  AND LOWER(l2v) = LOWER(@l2)
  AND DATE(r.reviewed_at) BETWEEN DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY) AND CURRENT_DATE()
```

**B. Total reviews (same TID + VID, last 30d):**
```sql
SELECT COUNT(DISTINCT r.booking_id) AS c
FROM `headout-analytics.analytics_reporting.fct_reviews` r
LEFT JOIN `headout-analytics.analytics_reporting.fct_bookings` b
  ON r.booking_id = b.booking_id
WHERE b.tour_id = @tid AND b.vendor_id = @vid
  AND DATE(r.reviewed_at) BETWEEN DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY) AND CURRENT_DATE()
```

**C. Similar support queries (same TID + VID, matching tags, last 30d) — exact-tag list variant:**
```sql
SELECT COUNT(DISTINCT sq.booking_id) AS c
FROM `headout-analytics.analytics_reporting.fct_support_queries` sq
LEFT JOIN `headout-analytics.analytics_reporting.fct_bookings` b
  ON CAST(b.booking_id AS STRING) = sq.booking_id
WHERE b.tour_id = @tid AND b.vendor_id = @vid
  AND sq.query_tag IN UNNEST(@tags)
  AND DATE(sq.query_created_at) BETWEEN DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY) AND CURRENT_DATE()
```

**C-alt. LIKE-any variant (only for Content L2):**
Same shape as C, replace `sq.query_tag IN UNNEST(@tags)` with a dynamically built `(LOWER(sq.query_tag) LIKE @pat1 OR LOWER(sq.query_tag) LIKE @pat2 OR …)` from the `like_any` list.

**D. Total support queries (same TID + VID, last 30d):**
Same as C, drop the tag filter.

**E. Rating windows (TID + VID, 15d + 30d):**
```sql
WITH bx AS (
  SELECT DISTINCT b.booking_id FROM `headout-analytics.analytics_reporting.fct_bookings` b
  WHERE b.tour_id = @tid AND b.vendor_id = @vid
)
SELECT
  ROUND(AVG(CASE WHEN DATE(r.reviewed_at) >= DATE_SUB(CURRENT_DATE(), INTERVAL 15 DAY) THEN r.rating END), 2) AS avg_rating_15d,
  COUNT( CASE WHEN DATE(r.reviewed_at) >= DATE_SUB(CURRENT_DATE(), INTERVAL 15 DAY) THEN 1 END)               AS n_ratings_15d,
  ROUND(AVG(CASE WHEN DATE(r.reviewed_at) >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY) THEN r.rating END), 2) AS avg_rating_30d,
  COUNT( CASE WHEN DATE(r.reviewed_at) >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY) THEN 1 END)               AS n_ratings_30d
FROM `headout-analytics.analytics_reporting.fct_reviews` r
JOIN bx ON bx.booking_id = r.booking_id
WHERE r.rating IS NOT NULL
```
