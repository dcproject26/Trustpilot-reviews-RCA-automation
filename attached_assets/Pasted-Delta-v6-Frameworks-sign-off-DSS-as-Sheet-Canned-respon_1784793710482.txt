Part 2 — DSS: rewrite services/dss.py from webhook to Sheet lookup
Scope change from earlier design. DSS is no longer a Retool webhook — it's a Google Sheet with CE/RO and Escalations paths. Use CE/RO only. Do NOT fall back to the webhook code.

Secrets to read:

DSS_SHEET_ID          (add default: 1sz8KkxiBaGSxiQy4G-iPN_0gmzGg4wt3V8NI0MaVd88)
DSS_SHEET_TAB         (default: "CE/RO" — but auto-detect if that fails; see below)
Fetch strategy:

On startup (and every 15 min via a simple TTL cache), fetch the sheet as CSV:
https://docs.google.com/spreadsheets/d/{DSS_SHEET_ID}/export?format=csv&gid={gid}
First try gid=0. If the sheet has multiple tabs, use the Sheets metadata JSON endpoint to find the tab that matches DSS_SHEET_TAB (case-insensitive, whitespace-normalised):
https://sheets.googleapis.com/v4/spreadsheets/{DSS_SHEET_ID}?fields=sheets.properties(title,sheetId)&key={GOOGLE_API_KEY}
If GOOGLE_API_KEY isn't set, fall back to the public CSV export at gid=0. Log which path was used.

The sheet is publicly shared for read. No OAuth needed if the CSV endpoint returns 200. If it returns 302/401, log and fall back to mock.
Parse:

Read the CSV, first row = headers.
Column detection is heuristic because I don't know the exact column names yet. Match column headers by keyword, case-insensitive:
Situation → header contains any of: situation, case, scenario, issue
Action → header contains: action, co action, ce action, ro, response, resolution
Compensation → header contains: comp, hoc, refund, credit
Policy → header contains: policy
Owner/team → header contains: team, owner, route
Filter rows where team/owner column matches CE, RO, or is empty. Skip rows where team = Escalations.
Build an in-memory list: [{situation, action, compensation, policy, raw_row}, ...].
Log column mapping on startup so we can verify: [dss] mapped columns: situation=<>, action=<>, compensation=<>.
Matching for get_recommendation(booking, l1, l2, review_text):

Score each row against the input:
+3 if the row's situation cell contains the L2 name (case-insensitive)
+2 if it contains the L1 name
+1 for each meaningful keyword overlap between situation and review_text (min 4 chars, stopwords stripped)
Return the top-scored row as:
{
  "policy":       row.policy or "",
  "compensation": row.compensation or "",
  "action":       row.action or "",
  "coverage":     "CE/RO",
  "escalateTo":   "",              # empty — we skip Escalations rows
  "matched_row":  row.raw_row,     # for debug
  "match_score":  int,
}
If no row scores > 0, return empty dict + match_score: 0, log warning.

Options loader (near existing L2_OPTIONS):

const SUB_THEME_OPTIONS = {};
async function loadSubThemeOptions() {
  try {
    const t = await (await fetch('/api/taxonomy')).json();
    const fw = t.sub_theme_frameworks || {};
    for (const key in fw) {
      const f = fw[key];
      const opts = (f.sub_themes || []).map(([code, name]) => code + '. ' + name);
      if (f.exclusion_label) opts.push(f.exclusion_label);
      SUB_THEME_OPTIONS[key] = opts;
    }
  } catch (e) {}
}
